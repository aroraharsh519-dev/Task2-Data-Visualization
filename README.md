# Superstore Sales Dashboard

## Objective
Create visualizations and business insights using the Superstore sales dataset in Power BI.

## Tools Used
- Power BI Desktop

## Dataset
- Sample Superstore Dataset

## Dashboard Components
- Total Sales KPI
- Total Profit KPI
- Sales Trend by Order Date
- Sales by Region
- Sales by Category
- Profit by Category

## Key Insights
1. Total Sales reached 2.30 Million.
2. Total Profit reached 286.40 Thousand.
3. Technology generated the highest sales.
4. The West region recorded the highest sales.
5. Sales showed a positive trend over time.
6. Different categories contribute differently to overall profit.
